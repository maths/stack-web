Introductions and updates from members

We started with introductions and updates from members, since it has been some time from the last meeting. Also, we welcomed new members.

Update about the STACK conference in Nairobhi (Zuma and Santiago):

  • A major success, with nearly 90 attendees from multiple countries and the highest level of African participation to date.
  • Successful fundraising enabled financial support for several participants to attend.
  • African STACK network: New ideas emerged for strengthening collaboration and developing the STACK community in Africa.
  • STACK Question Type Analytics plugin: Developed over the summer with a colleague from Calhau Tech to simplify the analysis of STACK question data. Aims to help identify potentially faulty or difficult questions across Moodle quizzes, without requiring users to download CSV files or write Python code. The plugin is available for initial testing. Colleagues are invited to try it and share feedback on Zulip.

Santiago gave an update about the multi-agent AI system.

He's done agood progres with that. The system includes an interface for previewing questions directly from XML files, with further development and a potential publication planned.

Goeorge gave updates from ETH

  • Improving STACK PRTs: ETH highlighted a case study by Andreas Steiger on using AI to improve Potential Response Trees (PRTs), particularly for exam questions with plans to replicate the AI-assisted PRT improvement approach for linear algebra questions.
  • STACK in chemistry: Progress has been made in applying STACK to chemistry, expanding its use beyond mathematics, with thanks to Matti.

Martin has resumed the development of Meclib library after a break, with AI assistance supporting development. He aims to improve the usability of complex questions and extend Meclib with new objects and feedback functions, alongside a mechanics course.

About STACK

STACK is the world-leading open-source automatic assessment system for mathematics and STEM. It is available for Moodle, ILIAS and as an integration into other systems through LTI.
