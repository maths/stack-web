#### Abstract

[Pretext](https://pretextbook.org/) is an authoring system for interactive digital textbooks.
Textbooks are authored in a text-based format (XML; though on-the-fly conversion from LaTeX
and Markdown is in the works). PreTeXt follows the philosophy "Write Once, Read Anywhere",
meaning that an authored book can automatically be deployed in different formats, such as
an interactive web version, PDF or an ebook. PreTeXt supports interactive elements such as
JSXGraph applets and Sage code cells, but also interactive questions with instant feedback
such as WebWork, MyOpenMath, Doenet, multiple-choice questions, and since recently also STACK.

In this seminar I will show how to set up a basic PreTeXt project and show a few features of
PreTeXt. I will then proceed to include STACK questions and discuss considerations around
question maintenance as well as limitations regarding data collection.
I will also touch upon options for converting content from other formats.
