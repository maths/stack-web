#### Abstract

In 2026 we added free-text inputs to STACK. The goal of these inputs is to allow students to type complete mathematical arguments, with mathematics embedded into text using ASCII-math and LaTeX.  We can also allow students to embed calculations.  Flexible “extractor” functions enable authors to automatically assess this input with existing STACK technology, and Moodle’s quiz has “manual grading options” as well.  This seminar will discuss this input and also how it will play a central role in our AI-enabled input system.
